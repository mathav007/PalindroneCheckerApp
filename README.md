# 🔁 PalindromeCheckerApp

## 📖 Project Overview
PalindromeCheckerApp is a simple Java application that checks whether a given string is a palindrome.

A palindrome is a word, number, or phrase that reads the same forward and backward.

### ✨ Examples
- madam → ✅ Palindrome
- level → ✅ Palindrome
- hello → ❌ Not a Palindrome

2. Cloned the repository to local system using:
   ```
   git clone repository_link
   ```
3. Opened the project in IntelliJ IDEA.
4. Created a new module named **App**.
5. Created a Java class file named **PalindromeCheckerApp** inside the `src` folder.
6. Created a new branch using:
   ```
   git checkout -b branch_name
   ```
7. Implemented palindrome checking logic in the class file.
8. Added only the required file using:
   ```
   git add App/src/PalindromeCheckerApp.java
   ```
